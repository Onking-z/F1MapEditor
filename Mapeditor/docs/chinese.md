# 简体中文界面

源码版支持独立的 `zh` 语言选项，原有英语和德语继续保留。

- 在 **View / 视图 → Sprache / Language / 语言 → 简体中文** 中切换，无需重启。
- 命令行：`python -m mapeditor --sprache zh`。
- 当前机器可双击 `E:\F125mod\启动Mapeditor-中文版.cmd`，该入口明确以中文启动。
- 原来的 `启动Mapeditor-比赛参数.cmd` 沿用界面中保存的语言选择。

翻译范围：1329 条界面文字、460 条消息模板、66 条规则标题，以及帮助文档。
包括赛道比赛参数面板、回放摄像机、载体包设置和游戏赛道导入等功能。

界面翻译在 `src/mapeditor/i18n/texte.csv` 的 `zh` 列，消息在 `meldungen.csv`，
规则标题在 `regeln.csv`，帮助在 `hilfe_zh.html`。维护脚本保存表格时会保留中文列。
消息模板和界面参数的花括号占位符、文件筛选表达式、复数分隔符均保留。

中文使用小数点；可以在布尔值输入框中输入“是／否”“开启／关闭”。
Qt 标准按钮使用随 PySide6 提供的简体中文翻译，打包规则会保留对应 `.qm` 文件。
来自游戏、第三方工具或未知模板的消息，以及用户自定义名称，可能仍按原文显示。

此修改属于源码版，不替换此前的 0.3.0 打包程序。
