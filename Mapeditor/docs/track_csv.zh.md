# 扩展赛道 CSV v1

入口：项目 → 从模板新建 → 扩展赛道 CSV v1。
文件为 UTF-8、逗号分隔 CSV，第一行为字段名；允许以 # 开头的说明行。
至少 8 个采样点，按行驶方向排列；路线闭合。末行无需重复首行。
导入不平移、不旋转、不缩放、不减少采样点，平面采用 TUM 坐标：编辑器 x=x_m、z=-y_m，height_m 为竖直高程。

## 字段

必填：x_m,y_m,w_tr_left_m,w_tr_right_m。所有长度以米计，左右按行驶方向。

可选逐点字段：

| 字段 | 含义 |
| --- | --- |
| height_m | 中心线高程，空白时为 0；纵坡由高程变化形成 |
| bank_deg | 横坡角，正值左侧高于右侧；空白使用生成器属性插值/默认值 |
| kerb_left_width_m / kerb_right_width_m | 左右路肩宽度，0 表示无路肩 |
| verge_left_width_m / verge_right_width_m | 左右路侧带宽度 |
| runoff_left / runoff_right | grass、gravel、asphalt，分别映射草地、砂石、沥青 |
| side_left_slope_deg / side_right_slope_deg | 路侧坡度，正值向外升高 |
| wall_left_distance_m / wall_right_distance_m | 从路面边缘到护墙的距离，至少 0.5 m；不是中心线距离 |

可选整条赛道统一字段：wall_height_m（墙高）、wall_thickness_m（墙厚）、edge_line_width_m（路面边线宽）。
可只在一行填写；多行填写时必须相同，否则导入报错。

路侧字段按当前点至下一点区间生效，最后一点至首点闭合；区间依据导入后曲线的真实弧长建立。
空白路侧字段表示该区间使用生成器默认规则，不表示沿用上一行；0 与空白不同。
若重复首行作为末行，其全部属性也必须相同。
不接受未知字段、重复列、无穷/NaN、负宽度及不一致的行长度。

这是一种新的导入格式，不是标准 TUM 扩展约定。普通 TUM CSV 仍走原有入口。
不支持路肩类型/独立高度、护墙类型/开关/缺口/独立墙脚高程、独立缓冲区宽度、独立路缘高程。

生成器仍会使用曲线连接采样点，并可能平滑路侧、限制宽度、避让护墙。保留输入不等于逐点还原实测几何。
导入不会取消游戏范围检查，大赛道仍须使用已有的大地形选项并实际测试。
