Mapeditor – 使用方法

快速开始

  1. 创建赛道：项目 → 新建，然后选点(P)点击地图 – 或 从模板… / 生成建议…。
  2. 闭合圈(至少四个点)：圈保持开放时，工具栏按钮会点亮。随后会 自动计算预览。
  3. 微调：拖动点，在右侧属性中修改数值，在高程剖面中检查高程。
  4. 检查(Ctrl+Enter)：下方检查中列出消息，点击可跳到对应位置。
  5. 构建：生成给 Track Installer 的包；随后在游戏中实测，并在实测中记录结果。

显示与隐藏

每项功能都可显示或隐藏：视图 → 地图图层(网格、边缘、方向、可行驶区、区域、 赛车线、维修区/发车位/分段、弯道编号、输入点、标签、比例、提示标签)，区域(侧边面板、 属性、下部区域、超高字段、工具栏、标题栏和状态栏)，单个标签页和自动化(赛车线、 自动保存、打开上次项目、起始界面)。一览无余：自定义视图…(Ctrl+Shift+A)； 全部显示恢复所有内容。设置会被记住。Ctrl+M 或双击标签页 可最大化下部区域。 视图 → 语言可立即在简体中文、英语和德语之间切换，无需重启(项目、 撤销历史、预览和地图视图保持不变)。

左栏

显示和点列表点击标题即可展开或收起。长列表初始为收起状态，在 点工具中展开。放大和缩小(也可用 Ctrl + 和 Ctrl −)位于视图菜单。 填充间隙在圈已闭合且满足以下条件时可用：某个间隙超过 20 m 且为常用点间距的四倍，或 选中了两个相邻点。右侧的超高框在有选择时以及超高标签页中出现。

拼接赛道：复制粘贴点

用Ctrl+C复制选中的点(或段)，用Ctrl+X剪切，再用Ctrl+V粘贴到 另一条或同一条赛道，也可在两个打开的 Mapeditor 窗口之间粘贴。快捷键在地图中有效，所有命令也都在 编辑菜单中。粘贴仅在开放的控制点赛道上有效：片段以其相配的一端接到两个开放端之一 (由距离和逆行驶方向的弯折决定，方向相反的片段会自动翻转)。若片段 距离超过 50 m，则移动到该开放端，否则保留原坐标。粘贴后片段处于选中状态，选择工具 处于激活状态，可移动和旋转该片段。若接在起点处，横断面区段和终点线会随片段长度一同移动。

在此处开放圈会在选中点之后打开已闭合的圈；若选中多个点，则删除这些点并在该处开放 圈。红圈标示粘贴片段与赛道重叠的位置；剪除重叠从开放 端的第一处重叠起截短所选片段。反转选择顺序可将片段掉头。最后执行闭合圈和 填充间隙。检查会拒绝交叉和跨越(GE-01)。

在图片上描摹赛道

项目 → 加载参考图…，或通过从剪贴板取参考图使用截图，可把一张地图图片作为模板放在 地图下方；图片以bildvorlage.png保存在项目文件夹中。在描摹工具(N)中，先 在右侧测量比例(在图片的比例尺上点两下)，并尽可能输入目标长度。 然后在终点线上点击起点，沿行驶方向设置更多控制点；编辑器会自动找出 中间的道路。它只接管完整、不自交且不重复经过同一路段的圈。红圈标示 出错的位置，橙色「B」提供第二条可行路径。用作赛道会将其转换为控制点赛道。地图视图 (手绘线)用少量点即可，航拍图需要更多点。

缩放赛道

编辑 → 缩放赛道…(属性 → 道路(整条赛道)下也有按钮)可按系数放大或缩小整条赛道，或将其调整到指定的长度 (米，初始值为当前预览的长度)。缩放以赛道中心为基准：点或段长及 半径、横断面区段、终点线、DRS 和直道模式区域、维修区入口和出口，以及环境 对象和山丘的位置。以米为单位的高程、宽度和对象尺寸保持不变，因此赛道变长后会变平缓。整个操作算一步， 可用 Ctrl+Z 撤销。

回放摄像机

构建时会将载体的回放、电视和维修区摄像机移至新赛道。车辆驶过触发区（横跨赛道的横条）时，导演会切换到该组摄像机。 摄像机（回放）图层会显示触发区和摄像机（菱形），虚线表示载体事件图中的关联。单击可选择摄像机组。 顶部工具栏中的摄像机工具（K）：拖动菱形可自由移动摄像机，拖动横条可沿赛道移动触发区。 自动计算摄像机会为当前赛道重新布局：触发区位于弯前，摄像机位于其后、弯道外侧。 放弃摄像机修改会恢复移至本赛道的载体布局。 在属性 → 摄像机（回放）中，可关闭某组、沿赛道偏移、向外移动或抬高摄像机；「所有摄像机」可关闭移动功能。 目前不能新增摄像机，数量来自载体。维修区摄像机会自动跟随维修区通道。

从游戏加载赛道

项目 → 从模板新建…，来源选择F1 25 游戏赛道：列表包含游戏中的全部赛道及反向布局。 编辑器只读取游戏数据，不写入游戏目录。会导入中心线、高程和宽度，也可选择导入维修区通道、DRS 和直道模式区域、发车位， 驾驶物理数据中的两侧区域（路肩、草带、砂石或沥青缓冲区、护栏间距），以及场景（树木、建筑、帐篷等环境对象，不含位于新赛道路面上的对象）。 若赛道超出游戏世界范围，会先尝试旋转（例如蒙扎、斯帕、巴库）；仍不适配时才提示缩小。铃鹿通过桥梁交叉，当前无法构建。 其他文件…可读取 Mod 的 ERP 或安装包，但场景只能从 ERP 导入。 包含原版赛道布局的安装包中含有从游戏数据衍生的内容，仅供个人使用，不应分享。

查找与恢复

转到(列表上方的输入框)：距终点的米数(如 1250)、弯道(T4)或对象(#12)。列表 为每个点显示里程和弯道。项目 → 最近打开和起始界面提供最近的项目。 编辑器每分钟把未保存的更改写入项目文件夹中的.mapeditor_wiederherstellung.json； 崩溃后打开项目时会提供这些更改(恢复操作可撤销)。

分段赛道

拖动段的末端可改变其长度或角度，拖动圆弧上的黄色方块可改变其半径。左侧：插入 直线/圆弧、拆分、更改类型。若要自由编组编辑，使用「转换为控制点」。

高程与坡度(高程剖面标签页)

每个控制点或段末端都是高程线上的手柄。水平拖动可选择范围 A→B，垂直拖动可改变高程(0.1 m 网格，一步撤销；选中的点一起移动)。 剖面上方的按钮：A→B 平滑过渡(两端无折角的 S 形曲线)、坡道、同高程、 平滑。↑/↓ 0.1 m，按住 Shift 为 1 m。右键单击：均匀坡度(在第一个和最后一个选中 点之间生成坡道)、同高程、平滑、输入高程。点与点之间以 % 显示坡度(超过 8 % 显示为红色)。 滚轮水平缩放，鼠标中键平移，双击显示整圈。 选择与地图和列表联动。

超高(向侧面倾斜)

选中弯道或点，在右侧超高字段中设置数值(快捷按钮：平、2°、4°、 FIA 最大)并选择方向：弯道内侧更低会适配每个弯道，直道上则用 左侧更高或右侧更高。更改只影响所选内容；生成器会平滑过渡。 所有弯道自动按弯道半径对整条赛道做超高(急弯达到设定值，R 500 m 起为平)， 全部为平会清除所有超高。检查：见下方的超高和横断面标签页。 在超高标签页中可像高程剖面那样编辑超高：垂直拖动点(对段则拖动段的 中点)，水平拖动可选择范围 A→B，↑↓ 以 0.1° 步进(按住 Shift 为 1°)，按钮或 右键：A→B 平滑过渡、坡道、相同值、平滑、输入超高…。 每次更改算一步撤销。

编辑横断面

横断面标签页，右侧编辑横断面面板：范围从/至为距终点的 米数(按钮选择 A→B或光标 ±50 m)，侧别(左、右、行驶方向两侧)，然后设置 道路(半宽)以加宽或收窄沥青路面，路肩(0 = 无)、草带、缓冲区(草地、 砂石或沥青)以及护栏距离。保留在自动或不变的字段会沿用 生成器的自动布局(弯道有路肩，急弯之后有砂石)。应用会设置该区段， 自动会删除范围内自定义的区段。护栏最多向外移动到通往下一个赛道部分仍有 空间为止；在维修区通道处，维修区通道优先。沥青缓冲区的构建在游戏中使用 维修区通道的沥青和道路的行驶物理。

赛车线(赛车线、刹车点、弯道)

每次更改后，生成器都会在后台计算赛车线(依赛道不同需 10–50 s， 可在左侧开启自动计算赛车线；否则用检查，Ctrl+Enter)。地图中： 赛车线红色 = 刹车，黄色 = 滑行， 绿色 = 全油门；红色三角 = 刹车点(放大时显示 km/h)， 白色方块 = 距离牌，T1 … = 与游戏中一致的弯道编号(构建时会合并超过 15 个弯道)， S2/S3 = 分段边界，白点 = 发车位，橙色 = 维修区通道和维修区车库。标签页 速度：整圈的 km/h 曲线；分析：圈速和弯道表(点击行可跳到该弯道)。 更改后赛车线会变淡，直到新的赛车线算完。构建使用与其预检相同的结果 (同一状态不会重复计算)。

维修区通道

选择属性 → 维修区通道：入口和出口处会在地图上出现方块；拖动可沿赛道 移动它们(一步撤销)。随后赛车线会显示准确的维修区通道。 限速为 60 或 80 km/h，与游戏中的赛道一致；配合从赛道推算比赛数据(构建对话框)，它会连同 进站所需的时间一起写入游戏。

环境(树木、建筑、帐篷…)

标签页环境：游戏模型目录(搜索、类别、预览、尺寸)。选择一个模型并点击 地图即可放置(工具U)；点击对象可选中，拖动可移动，框选可选中多个，Del 删除，双击可选中整个组。工具B种植区域：拖出矩形或用 画笔涂抹，可设置密度(每公顷对象数)、模型组合(可选择多个模型)、随机旋转、缩放范围、 到赛道的最小距离(默认为墙后 15 m)、对象间距和种子(相同值 = 相同散布)。 每次散布是一个组，算一步撤销。对象以目录尺寸的圆形显示(颜色按 类别区分；视图 → 环境 可隐藏它们)。地被保留载体的草和杂草。检查会报告 未知模型，以及赛道区域之外或道路上的对象(点击可跳到该对象)。构建会读取 项目的umgebung.json文件。

地形：在地形框中，放置山丘会在下一次点击时把山丘放入赛道区域 (高度 −60 … 200 m，负值为洼地；可见且可行驶，构建时会向赛道方向压平)。 放置山峰会把山峰放在赛道区域之外(先缩小视图；高 10 … 2000 m，距中心最多 12 km； 仅作地平线背景)。拖动中心可移动它，高度和半径在框中修改，Del 可删除。带红色轮廓的形状位置不当，或在赛道区域边缘被截断。

构建与移植到游戏

载体包。每次构建都需要波尔蒂芒 Mod（约 2.9 GB，建议 1.0.2 版）。缺少载体时，「检查并构建」会询问文件位置或是否需要下载； 也可提前使用工具 → 设置载体包…。「从 Overtake 下载…」会在浏览器打开页面（下载需要免费 Overtake 账户，编辑器不会索取登录信息）， 随后只读监测下载文件夹，并在 ZIP 完整后提供选择。也可拖入 ZIP 或手动选取文件。编辑器会核对赛道和版本， 将文件复制到 %LOCALAPPDATA%\Mapeditor\traeger 供所有项目使用，原文件保持不变。

构建会建议下一个构建名称(如 testedit11)，并显示所需和剩余空间。 赛道代码：游戏数据库已知的所有代码(推荐：sochi)；下方显示该 代码是否已安装到游戏中，以及数据库是否已激活。多个自制赛道并存时 需要使用不同的代码。 移植到游戏…会通过快速交换把最近构建的包写入 F1 25：先显示计划，然后 每次都需要确认，并事先把受影响的游戏文件备份到工作文件夹旁的injektion_sicherung 中；随后会打开实测记录。EGO 编辑器无需运行：若 其中的 Mod 已停用，移植会自行恢复记忆的数据库激活状态。只有赛道代码的首次 安装及其首次激活(「激活 Mod」)需要通过一次 Track Installer 或 EGO 编辑器。工具 · 清理旧构建…在确认后删除旧构建和包。

构建目标：Swofty Launcher会创建 addon 而非包：由赛道名生成独立的赛道代码，该 名称也会出现在游戏菜单中，且不占用安装槽位。把 ZIP 拖到启动器的Addons页面，并从启动器 离线启动游戏，不使用 EA AntiCheat。此方式不需要快速交换，也不提供该功能。

安装到启动器和安装到启动器并启动会自动完成这些操作；首次使用时，编辑器会询问swofty.exe的位置。游戏结束后，对话框会显示含崩溃数据的会话摘要，并保存到工作文件夹。读取上次会话对从启动器启动的游戏做同样的事。 26 辆车发车格会把车位加入世界；车辆本身来自 Custom Grid Size 等 addon。

从选择取范围

若标出相连的点或段，例如在地图上框选，横断面标签页会把它们作为从/至范围，也可跨越终点线。若选择中有缺口，范围保持不变。尚未应用的输入会保留。

边缘角度

在横断面标签页中，边缘角度决定道路两侧的处理方式：水平为默认， 与赛道相同会在每个点之后的前 12 m 内延续超高，自定义角度使用固定值(正值 向外抬升)。范围和侧别的选择方式与其他字段相同，整圈取整条赛道。然后按 应用。

地面与周边

在高级构建选项下，自定义地面与周边贴图会替换模板的航拍照片：地面来自赛道表面，赛车线贴合沥青，周边与山丘和山峰一致。景观选择草地或沙漠(无地被)，色调把草地和周边调成干燥、繁茂或秋季色调。该选项默认开启。

属性

双击数值，修改后按 Enter。斜体 = 默认值(不保存)。清空字段会恢复 默认值。是/否和选项字段会打开下拉列表。小数分隔符可用逗号或小数点。 对点或段会显示总宽度(斜体：根据预览在该处的宽度，取自 相邻点、剖面区段或道路)； 非对称宽度：是会创建左/右半宽(以当前宽度为起点)，否会把它们 合并回总宽度。超高在上方的超高面板中设置(若将其隐藏，会以表格行的形式恢复)。 检查列表按错误、警告、提示排序，同一级别内按里程排序。

撤销与保存

每次完成的更改算一步：Ctrl+Z / Ctrl+Y。保存 Ctrl+S，新建 Ctrl+N，打开 Ctrl+O。

地图颜色

■ 输入(你设置的点，即时) · ■ 计算出的道路及边缘条带(变淡 = 已过期，正在重新计算) · ■ 可行驶区 ±1024 m(赛道必须位于其中) · ■ 直道模式 · ■ DRS

提示：检查消息、规则说明和构建日志中的已知消息模板会按当前界面语言翻译；未知消息保留原文。

赛道比赛参数

项目 → 赛道比赛参数…可指定硬胎、中性胎和软胎配方，编号须依次递增。 比赛与排位的单圈能量回收上限可分别设置，单位为 MJ（1 MJ = 1,000,000 J）。勾选后，手动参数会在构建时覆盖自动数据；未勾选则沿用载体或自动设置。 0 表示明确的零上限，不等同于取消覆盖。抓地力尚无已验证的可编辑字段，当前沿用载体。 点「确定」可应用，Ctrl+Z 可撤销；Ctrl+S 将其保存到项目。ERS 参数仍需游戏内验证。
